# Product

## Platform

web

## Stack

static HTML/CSS/JS on GitHub Pages (jellodev/junior-ko-world), no build step. Matches the sibling game repos.

## Users

Strangers arriving from a shared link (KakaoTalk, X, Instagram story) on a phone or laptop, with no idea who KO is. Secondary: friends who already played one game and want the others. (Inferred from the request; the owner delegated these decisions.)

## Product Purpose

One front door to KO's (jellodev) mini-games, so each new game has somewhere to live and every visitor of one game can find the rest. Success: a first-time visitor stops, thinks "어 이것봐라?", and opens at least one game.

## Positioning

A single maker's playground of small, odd, AI-era games — not a portal, not a studio. Each game is a self-contained joke with its own visual identity (KOTI: AI MBTI, 살려주세요.com: future AI court, 108번뇌 꿰기: needle-and-beads ordeal, 찰랑찰랑 볼록 대작전: pour-without-spilling).

## Capabilities and Constraints

- The list will keep growing; adding a game must stay a one-block copy in `index.html`. Copy must never enumerate the games.
- Thumbnails are each game's own published OG image (1200×630), hot-linked, not copied.
- No server, no analytics requirement, no login.
- Must work on mobile first; most traffic is a shared link opened on a phone.

## Brand Commitments

- Name in use: "KO WORLD". Owner handle: jellodev.
- Voice: KO speaks in casual 반말 to the visitor, like a newsletter editor ("안녕, KO야").
- References the owner chose: Toss (clean spacing, soft gray panels, rounded cards), 까탈로그 and 주말랭이 (personal curation voice, bylines).
- Rejected directions: pink Win98 explorer, OFFF-style black window, Seoul metro line. All read as "AI-made"; gimmick concepts are out.

## Evidence on Hand

Four live games with OG images. No press, users counts, or testimonials — none may be invented.

## Product Principles

- The games are the content; the hub frames them, never competes with them.
- Curiosity first: the first screen must make a stranger want to touch something.
- Growth without edits: nothing in the layout or copy assumes a fixed number of games.
