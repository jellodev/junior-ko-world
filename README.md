# 쥬니어 KO 월드

jellodev 가 만든 미니게임을 한곳에서 고르는 모아보기 페이지. 빌드·JS 없는 정적 HTML 한 장이다.

각 카드의 썸네일은 게임 저장소가 이미 배포한 OG 이미지를 그대로 가져다 쓴다. 게임 쪽 공유 이미지를 바꾸면 여기도 따라 바뀌므로 별도로 복사해 두지 않는다.

새 게임을 추가할 때는 `index.html` 의 `<li>` 카드 하나를 복사해 링크·이미지·문구를 바꾸고, 카드 색은 `mint` · `berry` · `lemon` 중 하나를 고른다.

## 로컬 실행

```bash
python3 -m http.server
```
