# 쥬니어 KO 월드

jellodev 가 만든 미니게임을 한곳에서 고르는 모아보기 페이지. 흐릿한 놀이동산 바탕화면 위에 탐색기 창 하나가 떠 있고, 게임은 그 안의 `.exe` 아이콘이다. 빌드 없는 정적 HTML.

- 데스크톱은 진짜 탐색기처럼 한 번 누르면 선택(왼쪽 "자세히"에 설명), 두 번 누르면 실행한다. 터치 기기에서는 더블탭이 확대와 겹치므로 한 번 탭으로 바로 실행한다. 키보드 Enter 도 바로 실행이다.
- 배경 `park.svg` 는 직접 그린 일러스트를 CSS 로 흐리게 한 것이다. 사진으로 바꾸고 싶으면 `style.css` 의 `body::before` 이미지만 바꾸면 된다.
- 픽셀 폰트는 Galmuri11(OFL), 큰 글씨는 Jua.

새 게임을 추가할 때는 `index.html` 의 `<li>` 하나를 복사해 링크·`data-desc`·이모지·`--tile` 색·파일 이름을 바꾼다. 개체 수는 스크립트가 센다.

## 로컬 실행

```bash
python3 -m http.server
```
