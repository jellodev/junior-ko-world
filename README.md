# KO WORLD

jellodev(KO)가 만든 미니게임 모아보기. 서울 지하철 노선도 형식이다. 게임 하나가 역 하나이고, 노선 끝의 점선 "다음 역 공사 중"이 앞으로 늘어날 게임 자리다. 빌드 없는 정적 HTML.

## 왜 지하철인가

- 게임 목록이 계속 늘어난다. 카드 그리드는 개수가 늘면 그냥 길어질 뿐이지만, 노선은 "연장"이라는 의미가 생긴다. 문구에 게임 이름을 나열하지 않는 것도 같은 이유다.
- 한국 방문자라면 누구나 읽을 줄 아는 시각 언어다. 역 번호(K01), 역명 아래 영문, LED 안내("이번 역은 ○○ 역입니다"), "내리실 문은 오른쪽입니다" 같은 말투를 설명 없이 알아듣는다.
- 열차 안 노선도처럼 "지나온 역"을 회색으로 칠하는 방식은 일부러 쓰지 않았다. 방문자는 이동하는 승객이 아니라서, 회색 역은 닫힌 게임처럼 보였다.

## 동작

- 데스크톱: 가로 노선도. 역에 마우스를 올리거나 Tab 으로 포커스하면 열차가 그 역으로 가고, LED 가 바뀌며, "하차하기"가 그 게임을 연다. 화면보다 노선이 길면 오른쪽이 흐려지고 마우스 휠로 가로 스크롤된다.
- 폰(899px 이하): 세로 노선도. 화면 가운데에 온 역이 현재 역이 된다. 넓은 터치 화면은 가로 노선을 밀면 가운데 역이 현재 역이 된다.
- 게임에 갔다가 뒤로가기로 돌아오면 내렸던 역에 열차가 그대로 서 있다(탭 단위 sessionStorage). 처음 들어올 때만 열차가 진입하는 연출이 나온다. 매번 처음부터 다시 진입하면 돌아온 사람에게는 리셋처럼 느껴진다.
- 썸네일은 각 게임이 배포한 OG 이미지를 그대로 링크한다.
- 글꼴: Pretendard(본문·역명), Galmuri11(LED).

## 게임 추가

`index.html` 에서 마지막 실제 역 `<li class="station">` 하나를 복사해 링크·역 번호·이름·영문·한 줄 설명·OG 이미지를 바꾸고, "다음 역 공사 중" 앞에 둔다. 노선 길이와 다음 역 안내는 스크립트가 센다.

## 로컬 실행

python3 -m http.server
