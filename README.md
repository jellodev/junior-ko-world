# KO WORLD

KO(jellodev)가 만든 미니게임 모음. 만든 사람이 자기 말투로 게임을 하나씩 소개하는 피드다. 빌드도 JS도 없는 정적 HTML 이다.

## 왜 이 모양인가

- 지하철 노선도, 윈도우 탐색기 같은 장치형 컨셉을 거쳤지만 "AI가 만든 사이트 같다"는 평가를 받았다. 장치는 영리해 보이려는 티가 나고, 정작 만든 사람이 안 보였다.
- 레퍼런스는 토스(정돈된 여백, 연회색 패널, 둥근 카드), 까탈로그와 주말랭이(사람이 반말로 말 거는 큐레이션, 바이라인)다. 그래서 게임 설명은 KO의 말투로 쓰고, 카드마다 작성자와 날짜를 단다.
- 날짜는 각 게임 저장소의 첫 커밋 날짜다. 인기 순위나 플레이 수처럼 근거 없는 숫자는 넣지 않는다.
- JS 가 없으니 뒤로가기는 브라우저 기본 동작 그대로다.

## 게임 추가

`index.html` 의 `<ol class="feed">` 맨 위에 `<li>` 카드 하나를 추가한다. 맨 위 카드는 CSS 가 알아서 크게 보여 준다. "새로 나왔어" 태그는 새 카드로 옮기고, 이전 카드에서는 지운다.

카드에 들어갈 것: 링크, 게임 OG 이미지와 alt, 태그(손맛 게임/AI 놀이), 제목, KO 말투의 한두 문장 소개, 첫 커밋 날짜.

`og.png` 는 링크 공유 미리보기다. 게임 구성이 크게 바뀌면 다시 만든다.

## 로컬 실행

```bash
python3 -m http.server
```
